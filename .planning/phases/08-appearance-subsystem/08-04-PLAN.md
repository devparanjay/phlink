<objective>
Make the appearance system **user-controllable**. Wire the integer pref `prefs::kPhlinkAppearanceMode` (D-04, default Follow System per D-06), the system-follow observer (D-10), and the chrome://settings/appearance radio row (D-05). After this plan a user can pick Light / Dark / Follow System and see the chrome flip live without a restart, with no telemetry on the change (CONTEXT carry-forward from Phase 6).

Purpose: Without 08-04 the locked palettes from 08-02/08-03 are unreachable to end users. This plan also ships the only WebUI surface in Phase 8 — Phase 5-06b (adblock toggle) and Phase 7-01/04 (perf settings) inherit this row's pattern.
Output: pref registration, observer + unit test, settings UI rows + grd strings, patch 0113. **One human verification checkpoint** at the end (visual confirm + radio behaviour).
</objective>

      ~PhlinkAppearanceObserver() override;
      // ui::NativeThemeObserver:
      void OnNativeThemeUpdated(ui::NativeTheme*) override;

      void OnPrefChanged();
      void Invalidate();
