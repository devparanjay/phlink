<interfaces>
**WCAG 2.2 SC 1.4.3 / 1.4.11 thresholds (D-07):**
- Normal text: contrast ≥ 4.5:1
- Large text / non-text UI components: contrast ≥ 3.0:1

**Pairs to gate (derived from D-08 + stitch-output.md §2.3):**

Normal-text pairs (must be ≥ 4.5:1):
1. (kColorPhlinkText, kColorPhlinkCanvas) — Light: 17.4:1, Dark: 19.7:1
2. (kColorPhlinkText, kColorPhlinkSurface) — Light: 16.0:1, Dark: 16.7:1
3. (kColorPhlinkText, kColorPhlinkCard) — Light: 17.4:1, Dark: 16.7:1
4. (kColorPhlinkTextMuted, kColorPhlinkCanvas) — Light: 7.5:1, Dark: 8.5:1
5. (kColorPhlinkTextMuted, kColorPhlinkSurface) — Light: ~7:1, Dark: ~8:1
6. (kColorPhlinkOnAccent, kColorPhlinkAccent) — Light: 11.4:1, Dark: 16.0:1 (covers the never-white invariant)
7. (kColorPhlinkText, kColorPhlinkSurfaceAlt)

Non-text UI pairs (must be ≥ 3.0:1):
8. (kColorPhlinkHairline, kColorPhlinkCanvas) — borders against canvas
9. (kColorPhlinkHairline, kColorPhlinkSurface) — borders within surfaces

**Acknowledged exception (per stitch-output.md §2.3):** `(kColorPhlinkAccent, kColorPhlinkCanvas)` Light yields 1.5:1 — handled by 2px stroke + check icon (semantic redundancy per WCAG SC 1.4.11). This pair is **deliberately NOT in the gated tables.** The pair tables only contain pairs that MUST pass; the design-time exception is documented in code comments referencing stitch-output.md §2.3.

**WCAG 2.2 luminance formula** (used by both layers):
```
For each channel c in {R, G, B} (sRGB 0..1):
  c_lin = (c <= 0.03928) ? c/12.92 : ((c + 0.055) / 1.055) ** 2.4
L = 0.2126 * R_lin + 0.7152 * G_lin + 0.0722 * B_lin
ratio(L1, L2) = (max(L1,L2) + 0.05) / (min(L1,L2) + 0.05)
```
