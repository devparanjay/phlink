# tests/branding-audit/allowlist.txt

# Phase 4.7 (BRND-01) — Acceptable "Chromium" / "Google Chrome" string
# matches in the built phlink bundle. Any string in the binary that
# matches /\bchromium\b|google chrome/i must be covered by an entry
# in this file (substring match). The categories below are the only
# justifications that should ever be added.
#
# Format: one fixed substring per line. Lines starting with `#` or
# blank lines are ignored. The match is case-insensitive substring
# (audit.sh normalizes both sides).
#
# Categories:
#   third-party-debug-path  — file paths embedded in __FILE__ / __builtin_FILE
#                             from third_party/ subtrees that vendor
#                             chromium-flavored sources. Not user-visible.
#   devtools-url            — bug-tracker / docs URLs printed in DevTools
#                             console errors and dev-only diagnostics.
#                             Power-user surface; acceptable.
#   grd-translation-ex      — <ex>Chromium</ex> translation-hint text
#                             baked into untranslated string blob. The
#                             runtime string substitutes IDS_PRODUCT_NAME
#                             ("phlink"); the <ex> is example-only.
#   gl-renderer             — OpenGL ES *Chromium* GL_RENDERER strings.
#                             Fingerprintable — tracked separately under
#                             a future fingerprint-hardening phase.
#   brand-check-guard       — guards on `is_chrome_branded` that print
#                             "...not allowed in Google Chrome..." but
#                             are inert in phlink (we are not chrome-branded).
#   native-messaging-path   — `/Library/Application Support/Chromium/...`
#                             native-messaging host lookup paths. phlink
#                             does not ship native-messaging hosts; these
#                             paths exist for compat with Chromium-installed
#                             hosts only.
#   internal-symbol         — internal C++ symbol names / proto track-event
#                             namespaces that surface only in `strings`.
